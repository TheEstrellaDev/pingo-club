# Pingo Club — brief del proyecto

## Objetivo

Crear una primera versión comercial completa y responsive para Pingo Club, estética infantil en Guadalupe, Zacatecas. La experiencia debe transmitir confianza a madres y padres, y una visita alegre y amable a bebés, niñas, niños y adolescentes.

## Dirección de contenido

La frase de marca es “Estética infantil. Diversión en cada corte.” El sitio explica la propuesta con prudencia y enlaza a las redes proporcionadas. La ubicación que se publica es Calle Nieves y 2 de Mayo, Colonia Camilo Torres, detrás del Tec de Mty, Guadalupe, Zacatecas, México.

No se han inventado servicios concretos, precios, horarios, políticas, citas ni testimonios. Los datos comerciales ausentes se identifican como pendientes. El contacto oficial integrado es +52 492 125 5814 con enlaces de llamada y WhatsApp; las redes enlazan a los perfiles compartidos por el negocio.

## Secciones y funciones

- Navegación con enlaces a las secciones y menú móvil desplegable.
- Hero, presentación, bloque de servicios preparado para completar y sección de experiencia.
- Galería con ampliación, controles anterior/siguiente y cierre por Escape o clic exterior.
- Preguntas frecuentes tipo acordeón.
- Dirección con búsqueda en Google Maps e Instagram/TikTok.
- Footer con marca, navegación, ubicación general y año dinámico.
- Metadatos básicos para buscadores y compartir.

## Arquitectura

React + TypeScript + Vite. `App.tsx` contiene el contenido de una página y estados de menú, acordeón y galería. Estilos separados entre componentes (`App.css`) y base (`index.css`). Los archivos originales se conservan en `src/assets/images/`. Vite mantiene `base: '/pingo-club/'` para GitHub Pages.
